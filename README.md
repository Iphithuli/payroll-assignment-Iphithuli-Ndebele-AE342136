# Gauteng City College Employee Payroll System

## Project description
A C++ console application that calculates employee bonuses and total monthly pay. It processes one or more employees and prints a clearly labelled payslip for each employee.

## Bonus rules
The bonus is calculated as a percentage of the employee's basic monthly salary:
- **Performance:** rating 1–2 = 0%; rating 3 = 5%; rating 4 = 10%; rating 5 = 15%.
- **Department:** Sales = 3%; IT = 2%; Finance = 2.5%; HR = 1.5%; Operations = 1%.
- **Years of service:** 0–1 years = 0%; 2–4 years = 1%; 5 or more years = 2%.
The three bonus amounts are added together. Total pay is basic salary plus total bonus.


## Example
Input:
- Number of employees: 1
- Employee ID: 101
- Name: Thabo Mokoena
- Basic salary: R15000
- Department: 2 (IT)
- Performance rating: 4
- Years of service: 3

Expected calculation:
- Performance bonus: R1,500.00
- Department bonus: R300.00
- Service bonus: R150.00
- Total bonus: R1,950.00
- Total pay: R16,950.00
